# Changelog

## 0.1.0

- Add schema-generated stable ACP v1 models and method descriptors.
- Add explicit unstable-v1 and draft-v2 protocol entrypoints.
- Add typed agent/client applications, sessions, middleware, capability
  checks, cancellation, and in-process composition.
- Add a bounded, bidirectional JSON-RPC 2.0 runtime with batch support.
- Add NDJSON and conditional stdio transports.
- Add experimental HTTP/SSE and WebSocket clients and servers with
  browser-safe conditional adapters.
- Add a dual-version protocol router, generated schema synchronization,
  conformance tests, examples, benchmarks, and release validation.
